# Trybewarts

Este projeto é um formulário de avaliação da Escola de Magia e Bruxaria de Trybewarts, desenvolvido como parte do módulo de **Fundamentos** do curso de desenvolvimento web da **Trybe**.

## 🚀 Sobre o Projeto
O projeto foi inicialmente desenvolvido em dupla com **João Kruschewsky**, mas foi posteriormente **refatorado do zero por mim**, focando em uma estrutura de código mais limpa, melhor organização do CSS e uma interface mais polida e responsiva.

## 🛠️ Funcionalidades
- **Sistema de Login:** Validação simples no cabeçalho da página.
- **Formulário Dinâmico:** Diversos tipos de campos (texto, rádio, checkbox e seleção de casa).
- **Contador de Caracteres:** Feedback em tempo real para o limite de 500 caracteres no campo de comentários.
- **Validação de Envio:** Botão de envio habilitado apenas após o aceite dos termos.
- **Layout Adaptável:** Ajustes para diferentes tamanhos de tela (responsividade).
- **Otimização de Tela:** Layout projetado para visualização completa em uma única tela (sem rolagem desnecessária).

## 🧰 Tecnologias Utilizadas
- **HTML5:** Estrutura semântica.
- **CSS3:** Flexbox, design responsivo e conformidade com regras de Stylelint.
- **JavaScript:** Manipulação de DOM e lógica de validação.
